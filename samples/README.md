# samples

百目を実際に走らせた結果の保存用フォルダです。`data/` は `.gitignore` で除外されるため、
残しておきたい実行結果はここにコピーします。

## 2026-09-29

50 人の仮想ペルソナ（`personas.json`）が 2026 年 9 月 29 日にウェブ検索して集めた 342 件
（`items.json`、URL 重複除去後 336 件）から作った俯瞰ダイジェストです。

- `digest.md` — Markdown 版（GitHub 上でそのまま読めます）
- `digest.html` — ブラウザで開く単一ファイルのビューア（ペルソナ別の絞り込み・検索付き）
- `digest.json` — 構造化データ

この回は Anthropic API ではなく Claude Code のセッション内でウェブ検索を代行したため、
2 人（美容インフルエンサー、料理研究家）は検索回数の上限に達して未収集です。
